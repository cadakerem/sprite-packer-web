# Sprite-Packer Web

A modern, browser-based Sprite Sheet packing tool built with React and Vite. Drag and drop PNG images, pack them efficiently using various algorithms, and export the generated Sprite Sheet and JSON metadata instantly.

## Features (Planned)
- **Drag & Drop Interface:** Upload loose PNG files easily.
- **Live Canvas Preview:** Real-time visualization of the packed sprite sheet.
- **Algorithm Options:** Choose between MaxRects, Skyline, etc.
- **Instant Export:** Download the combined PNG and coordinate JSON without any server processing.

## Tech Stack
- Frontend: React + TypeScript
- Build Tool: Vite
- Design: Vanilla CSS / Tailwind (pending)

## Development
```bash
npm install
npm run dev
```
